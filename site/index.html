governor.zoitra.com

Spend fewer tokens.
Ship tighter agent runs.

Governor keeps Cursor and VS Code agents inside a lean scope: meter open editors, warn on bloat, install ignore rules, and draft briefs from your selection.

Install the VSIX GitHub

Meter

See estimated tokens sitting in open editors before you paste another wall of context.

Ignore

One command installs a lean .cursorignore so agents skip lockfiles, media, and build output.

Brief

Turn a selection into a constrained brief you can drop into chat without dragging the whole repo along.

Bloat

Scan for heavy paths that quietly burn budget every time an agent indexes the tree.

Install

  1. Download governor-0.1.0.vsix from GitHub or build it locally.
  2. In VS Code or Cursor: Extensions → Install from VSIX... — or run code --install-extension governor-0.1.0.vsix / cursor --install-extension governor-0.1.0.vsix.
  3. Reload, then open the Governor activity bar icon.
